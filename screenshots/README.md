# Screenshots

This directory contains screenshots of the VaR-RiskLab dashboard.

## Dashboard Sections

1. **Portfolio Overview** — Key metrics: annualized return, volatility, Sharpe ratio, max drawdown.
2. **VaR Comparison** — Side-by-side comparison of Historical, Parametric, and Monte Carlo VaR.
3. **Expected Shortfall** — VaR vs. ES comparison with explanation.
4. **Backtesting** — Rolling VaR vs. actual losses with exception highlighting.
5. **Stress Testing** — Scenario analysis: -10%, -20%, -30%, and custom shocks.
6. **Methodology** — Plain-English explanations of all risk models.

Add your own screenshots here after running the dashboard with `streamlit run app.py`.
